# Budget Tracker CLI

Консольное приложение для учёта личных финансов на TypeScript. Позволяет управлять счетами и транзакциями, смотреть баланс и экспортировать историю операций в CSV.

## Запуск

Нужны Node.js 22.13 или новее и npm.

```bash
git clone https://github.com/MagEk1511/ts-hse-homework.git
cd ts-hse-homework
npm ci
npm start
```

Запуск с демонстрационными счетами:

```bash
npm start -- --demo
```

Для навигации используйте стрелки и Enter, для выхода — Ctrl+C. В меню доступны создание, переименование и удаление счетов, добавление, редактирование и удаление транзакций.

Данные хранятся в памяти до выхода. CSV-файлы сохраняются в папку `exports/`.

## Команды

```bash
npm run build      # Сборка проекта
npm run typecheck  # Проверка типов
npm test           # Автоматические тесты
npm run dev        # Компиляция при изменении файлов
npm run demo:all   # Все учебные примеры
```

## Структура

```text
src/          Код приложения
examples/     Примеры по отдельным темам
tests/        Автоматические тесты
```

Описание заданий, ссылки на решения и команды запуска примеров — в [HOMEWORKS.md](HOMEWORKS.md).
